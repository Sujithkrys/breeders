# Sample sources

All audio used by `scripts/compose-audio.mjs` is royalty-free:

- `sp/` — Sonic Pi sample library, CC0 1.0 (public domain), via the npm package `supersonic-scsynth-samples`. Provenance and original Freesound links are listed in that package's PROVENANCE.md.
- `piano8/`, `piano12/` — Salamander Grand Piano V3 by Alexander Holm, CC BY 3.0 (https://creativecommons.org/licenses/by/3.0/), via the npm packages `@audio-samples/piano-mp3-velocity8` and `@audio-samples/piano-mp3-velocity12`.
