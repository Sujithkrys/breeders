# Bencho Finds — UI motion inspiration catalog

Source: https://bencho.dev/finds (scraped 2026-10-13, 164 finds). Each find has the original X post, and Bencho hosts a clip at https://media.bencho.dev<clip>.

**Local copies:** all 164 clips are in `video references/bencho/` and named `NNN-<id>.mp4` (#80 is a single still, `.jpg`); NNN matches the # column below.
These are other designers' work: study them as **motion references** to rebuild our own way in Remotion; never copy them pixel-for-pixel or use their clips in our films.

Tags: Morph, Reveal, Press, Hover, Drag, Elastic, Select, Type, Refract, Scroll, Slide, Swipe, Parallax, Magnetic.
