The reference Reels are in `E:\Breeders\instareferece`: an Outship launch, an OpenAI-style launch, a Wise ad, the OpenAI Sans type film, a Framer vertical, a motion showreel and a personal intro with match cuts. More references are in `E:\Breeders\video references`. The ChatGPT "Work" and Gemini Omni launch films were also used as style references.

**Measured benchmarks to aim for:**
- 8–16 audible sound events per 10s. Impacts must punch through: don't over-compress, and duck the music under each hit.
- Voice-led ads keep the voiceover going for 87–100% of the runtime, in short punchy lines.
- A new visual every 0.4–3s, with 7–11 sound onsets in the first 3s. For product demos the user prefers calmer, readable 2.5–4s shots.

**Signature moves to reuse:**
- Match cuts and morphs.
- UI over real-looking imagery.
- A glass logo with a light streak.
- A cursor with a name tag.
- Pixel-mosaic transitions.
- Pill marquee rows.
- A single strong brand palette.
- Structure: problem, then product, then capabilities, then tagline.
- Not italic serif accents ([[no-serif-fonts]]).

**How to apply:** check new videos against these numbers before calling them done. Related: [[audio-library]], [[breeders-page]].
