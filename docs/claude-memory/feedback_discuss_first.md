Before building a video, resolve the user's doubts and agree on the plan. Don't start writing Remotion code because a storyboard has been proposed.

**Why:** the user stops at the storyboard stage to "figure out all and then move forward". Several full films were rejected after being built without agreed look frames.
**How to apply:** for each new video:
1. Present your understanding and the storyboard.
2. Show 2–3 still look frames in the exact type and colours.
3. Answer the user's questions.
4. Wait for an explicit go-ahead before implementing.
