All visuals are made by Claude in code. That means no Veo or other AI video or image generators, no stock footage and no outside tools. The page's whole point is "made in Claude".

**Why:** the user rejected a plan that needed Veo clips; the promise is that Claude makes everything.
**How to apply:** never propose generated footage or ask the user to make clips. Get realism from code:
- real-time 3D in Three.js (PBR materials, studio/HDR light, soft shadows, depth of field)
- canvas and GLSL shaders
- pixel-accurate HTML UI
- procedural textures
- film grain and lens effects
- the SFX library
